الوحدة الثانية: التحليل المكاني (Spatial Analysis)

📊 مقدمة في التحليل المكاني

التحليل المكاني (Spatial Analysis) هو مجموعة من التقنيات التي تهدف إلى فهم العلاقات والأنماط بين الظواهر الجغرافية المختلفة. يعتبر التحليل المكاني جوهر نظم المعلومات الجغرافية، حيث يحوّل البيانات الخام إلى معلومات قيمة تدعم اتخاذ القرار في مجالات الزراعة، البيئة، التخطيط، وإدارة الموارد.

🔍 استكشاف البيانات 📐 نمذجة العلاقات 📊 تحليل الأنماط 📈 التنبؤ المكاني

📍 Buffer Analysis (تحليل النطاقات)

تحليل النطاقات (Buffer) هو عملية إنشاء منطقة عازلة حول معالم جغرافية (نقاط، خطوط، أو مضلعات) على مسافة محددة. يُستخدم هذا التحليل لتحديد المناطق المتأثرة أو مناطق الحماية حول المعالم.

📌 أنواع النطاقات:

  • 📍 نطاق نقطي (Point Buffer)
  • 〰️ نطاق خطي (Line Buffer)
  • ▣ نطاق مضلعي (Polygon Buffer)
  • 📐 نطاق متعدد (Multiple Buffer)
⭕

مثال: مناطق حماية الآبار

📍 بئر مياه → نطاق 500 متر

منطقة حماية من التلوث

100m 200m 500m

🌾 مثال تطبيقي في الزراعة:

المشكلة: تحديد المناطق التي يجب عدم الرش فيها بالمبيدات حول الآبار.
الحل: إنشاء نطاق (Buffer) بمسافة 100 متر حول كل بئر، ثم استبعاد هذه المناطق من خطة الرش.

🔀 Overlay Analysis (تحليل التراكب)

تحليل التراكب (Overlay) هو عملية دمج طبقتين أو أكثر من البيانات المكانية لإنتاج طبقة جديدة تحتوي على معلومات مجمعة. يُستخدم هذا التحليل لدراسة التداخلات المكانية بين الظواهر المختلفة.

∩
Intersect (تقاطع)

يحتفظ فقط بالمناطق المشتركة بين جميع الطبقات.

مثال: المناطق التي هي تربة طينية و مناطق ري
∪
Union (اتحاد)

يحتفظ بجميع المناطق من جميع الطبقات، مع دمج المناطق المتداخلة.

مثال: دمج خرائط التربة مع خرائط استخدام الأراضي
✂️
Clip (قص)

يقص طبقة باستخدام حدود طبقة أخرى (مثل قص منطقة الدراسة).

مثال: قص خريطة الغطاء النباتي بحدود منطقة الدراسة
🔗
Dissolve (دمج)

يدمج المعالم المتجاورة بناءً على صفة مشتركة (مثل نوع التربة).

مثال: دمج قطع الأراضي حسب نوع المحصول

🌾 مثال تطبيقي في الزراعة:

المشكلة: تحديد المناطق المناسبة لزراعة القمح بناءً على نوع التربة و الانحدار و المناخ.
الحل: استخدام Intersect لدمج خرائط التربة، الانحدار، والأمطار لإنتاج خريطة الملاءمة الزراعية.

🔗 Spatial Join (الربط المكاني)

الربط المكاني (Spatial Join) هو عملية نقل البيانات الوصفية من طبقة إلى أخرى بناءً على العلاقة المكانية بينهما. يُستخدم لربط بيانات النقاط مع المضلعات أو الخطوط التي تحتويها.

📌 أنواع الربط المكاني:

  • 🔗 One-to-One (واحد لواحد)
  • 🔗 One-to-Many (واحد لمتعدد)
  • 📍 Join by Location (بالموقع)
  • 📊 Join by Attribute (بالسمات)
📋

مثال: ربط الآبار بمناطق الدراسة

📍 الطبقة الأولى: نقاط الآبار (بها بيانات العمق، الإنتاجية)

🗺️ الطبقة الثانية: مضلعات مناطق الدراسة

🔗 النتيجة: كل بئر يرتبط بالمنطقة التي يقع فيها

🌾 مثال تطبيقي في الزراعة:

المشكلة: حساب متوسط إنتاجية المحاصيل لكل حقل زراعي بناءً على نقاط العينات المأخوذة من الحقل.
الحل: استخدام Spatial Join لربط نقاط العينات (التي تحتوي على بيانات الإنتاجية) مع مضلعات الحقول، ثم حساب المتوسط لكل حقل.

🌾 أمثلة تطبيقية متقدمة في الزراعة والبيئة

🌱 مثال 1: تحديد مناطق الري المثلى
  • 📍 البيانات: خرائط التربة، الانحدار، مصادر المياه
  • 🔧 الأدوات: Buffer + Overlay + Spatial Join
  • 📊 النتيجة: خريطة أولوية الري
  • الخطوات: إنشاء نطاق 500م حول مصادر المياه → تراكب مع خرائط التربة → تحديد المناطق الأكثر احتياجاً
🌾 مثال 2: تحليل انتشار الآفات
  • 📍 البيانات: نقاط الإصابة، خرائط المحاصيل، بيانات المناخ
  • 🔧 الأدوات: Buffer + Density Analysis + Interpolation
  • 📊 النتيجة: خريطة خطر انتشار الآفات
  • الخطوات: إنشاء نطاقات حول نقاط الإصابة → حساب الكثافة → تقريب (Interpolation) لتوزيع الخطر
💧 مثال 3: إدارة الموارد المائية
  • 📍 البيانات: الآبار، الأحواض المائية، منسوب المياه
  • 🔧 الأدوات: Buffer + Overlay + Surface Analysis
  • 📊 النتيجة: خريطة حساسية الموارد المائية
  • الخطوات: تحديد الأحواض المائية → إنشاء نطاقات حول الآبار → تحليل منسوب المياه
🌍 مثال 4: تقييم التدهور البيئي
  • 📍 البيانات: صور فضائية، خرائط الغطاء النباتي، بيانات التربة
  • 🔧 الأدوات: Overlay + Spatial Join + Statistics
  • 📊 النتيجة: خريطة التدهور البيئي
  • الخطوات: تحليل NDVI → تراكب مع خرائط التربة → ربط مع البيانات المناخية → تحديد مناطق التدهور

أكواد برمجية تطبيقية

📍 ArcGIS Pro - Python (ArcPy)

# Buffer Analysis
import arcpy
arcpy.analysis.Buffer("wells.shp", "wells_buffer_500m.shp", "500 Meters")

# Intersect (Overlay)
arcpy.analysis.Intersect(["soils.shp", "landuse.shp"], "soils_landuse.shp")

# Spatial Join
arcpy.analysis.SpatialJoin("fields.shp", "yield_points.shp", "fields_yield.shp")

🟩 QGIS - Python (PyQGIS)

# Buffer Analysis
import processing
processing.run("native:buffer", {
    'INPUT': 'wells.shp',
    'DISTANCE': 500,
    'OUTPUT': 'wells_buffer_500m.shp'
})

# Intersect (Overlay)
processing.run("native:intersection", {
    'INPUT': 'soils.shp',
    'OVERLAY': 'landuse.shp',
    'OUTPUT': 'soils_landuse.shp'
})

🗄️ مقدمة في الجيوداتابيس (Geodatabase)

الجيوداتابيس (Geodatabase) هي قاعدة بيانات جغرافية متطورة تُستخدم لتخزين وإدارة البيانات المكانية والوصفية بشكل مركزي ومنظم. تعتبر الجيوداتابيس العمود الفقري لأي نظام معلومات جغرافي حديث، حيث توفر بنية متكاملة للبيانات تضمن التكامل، الدقة، والكفاءة في إدارة المعلومات المكانية.

📁 تخزين مركزي 🔗 تكامل البيانات ✅ جودة البيانات ⚡ أداء عالي

🗄️ مفهوم Geodatabase

الجيوداتابيس (Geodatabase) هي قاعدة بيانات علائقية مصممة خصيصاً لتخزين وإدارة البيانات المكانية (مثل النقاط، الخطوط، والمضلعات) مع البيانات الوصفية المرتبطة بها. توفر الجيوداتابيس بنية هرمية لتنظيم البيانات، مما يسهل الوصول، التحديث، والتحليل.

📌 مميزات Geodatabase:

  • ✅ تخزين مركزي للبيانات
  • 🔗 تكامل البيانات المكانية والوصفية
  • 🛡️ أمان وحماية البيانات
  • ⚡ أداء عالي في الاستعلامات
  • 📊 دعم للعلاقات المعقدة
  • 🔄 قابلية للتوسع والتطوير

🏷️ Feature Class

Feature Class هي مجموعة من المعالم الجغرافية من نفس النوع (نقاط، خطوط، أو مضلعات) التي تشترك في نفس نظام الإحداثيات و نفس السمات. تُعد Feature Class الوحدة الأساسية لتخزين البيانات المكانية في Geodatabase.

📌 أنواع Feature Class:

  • 📍 Point (نقطة)
  • 〰️ Line (خط)
  • ▣ Polygon (مضلع)
  • 📐 Multipoint (نقاط متعددة)
  • 📊 Annotation (نص)
  • 📏 Dimension (أبعاد)
📋

مثال: Feature Class للآبار

📍 النوع: Point

📋 السمات: Well ID, Depth, Yield, pH

🌐 الإحداثيات: UTM Zone 33N

🔗 العلاقة: مرتبطة بجدول الآبار

🌾 مثال تطبيقي في الزراعة:

Feature Class: Soil_Samples
النوع: Point
السمات: Sample_ID, Location, pH, EC, OM, NPK
الاستخدام: تخزين بيانات عينات التربة من الحقول الزراعية لتحليل الخصوبة.

🔢 Domains (النطاقات)

Domains هي قواعد التحقق من صحة البيانات التي تُطبق على الحقول في Feature Class. تضمن Domains أن القيم المدخلة تقع ضمن نطاق محدد أو تنتمي إلى قائمة مسموح بها.

📌 أنواع Domains:

  • 🔢 Range Domain (نطاق رقمي)
  • 📋 Coded Domain (قيم مسموحة)
  • 📅 Date Domain (نطاق زمني)
  • 🔣 Text Domain (نصي)
✅

مثال: Domain للتربة

📋 Soil_Type (Coded Domain)

  • • Sandy (رملي)
  • • Clay (طيني)
  • • Loam (مزيج)
  • • Silty (غريني)

📊 pH_Range (Range Domain) 4.5 - 9.0

🌾 مثال تطبيقي في الزراعة:

Domain: Crop_Type
النوع: Coded Domain
القيم: Wheat, Barley, Corn, Olives, Dates
الاستخدام: ضمان إدخال أنواع المحاصيل الصحيحة فقط في قاعدة البيانات.

📂 Subtypes (الأنواع الفرعية)

Subtypes هي تصنيفات فرعية داخل Feature Class تسمح بتطبيق قواعد مختلفة على مجموعات مختلفة من المعالم. يستخدم Subtypes لتنظيم البيانات وتطبيق Domains مختلفة لكل مجموعة.

📌 مميزات Subtypes:

  • 📊 تصنيف المعالم
  • 🔢 قواعد مختلفة لكل نوع
  • 📋 Domains مختلفة
  • ✅ جودة البيانات المحسنة
📂

مثال: Subtypes للحقول الزراعية

🌾 Feature Class: Fields

  • • Subtype 1: Wheat Fields (قمح)
  • • Subtype 2: Barley Fields (شعير)
  • • Subtype 3: Olive Orchards (زيتون)

كل نوع له Domain وسمات مختلفة

🔗 Relationship Classes (علاقات البيانات)

Relationship Classes هي صلات منطقية تربط بين Feature Classes أو جداول البيانات في Geodatabase. تسمح العلاقات بإنشاء روابط ديناميكية بين البيانات المكانية والوصفية.

📌 أنواع العلاقات:

  • 🔗 One-to-One (1:1)
  • 🔗 One-to-Many (1:M)
  • 🔗 Many-to-Many (M:M)
  • 🔗 Composite (مركب)
🔗

مثال: علاقة الآبار والعينات

📍 Feature Class: Wells (آبار)

🧪 Table: Water_Samples (عينات المياه)

🔗 العلاقة: One-to-Many (بئر واحد → عدة عينات)

🌾 مثال تطبيقي في الزراعة:

العلاقة: Fields ↔ Soil_Samples
النوع: One-to-Many
الاستخدام: ربط كل حقل زراعي بعدة عينات تربة مأخوذة منه، مما يسمح بتحليل التباين المكاني للخصوبة داخل الحقل الواحد.

🛰️ مقدمة في الاستشعار عن بعد

الاستشعار عن بعد (Remote Sensing) هو علم الحصول على المعلومات عن سطح الأرض أو الأجسام الموجودة عليه دون اتصال مباشر معها، وذلك عن طريق استشعار وتسجيل الطاقة المنعكسة أو المنبعثة من هذه الأجسام باستخدام أجهزة استشعار محمولة على طائرات أو أقمار صناعية.

🛰️ أقمار صناعية ✈️ طائرات 📡 أجهزة استشعار 🖼️ تحليل صور

📡 أساسيات الاستشعار عن بعد

مبدأ عمل الاستشعار عن بعد يعتمد على تفاعل الطاقة الكهرومغناطيسية مع الأجسام على سطح الأرض. يقوم جهاز الاستشعار بتسجيل الطاقة المنعكسة أو المنبعثة من الأجسام، ثم تحويلها إلى صور رقمية يمكن تحليلها واستخراج المعلومات منها.

🔑 العناصر الأساسية:

  • ☀️ مصدر الطاقة (الشمس)
  • 🌍 الهدف (سطح الأرض)
  • 🛰️ جهاز الاستشعار (Sensor)
  • 📡 نقل البيانات (Data Transmission)
  • 🖥️ معالجة البيانات (Data Processing)
  • 📊 تحليل وتفسير (Analysis & Interpretation)

// تحميل صورة Sentinel-2
var image = ee.Image('COPERNICUS/S2_SR/20230101T085031_20230101T085031_T34SCC');

// اختيار النطاقات
var red = image.select('B4');
var nir = image.select('B8');
var green = image.select('B3');
var swir = image.select('B11');

// حساب NDVI
var ndvi = nir.subtract(red).divide(nir.add(red));

// حساب NDWI
var ndwi = green.subtract(nir).divide(green.add(nir));

// حساب EVI
var evi = ee.Image(2.5)
  .multiply(nir.subtract(red))
  .divide(
    nir.add(ee.Image(6).multiply(red))
    .subtract(ee.Image(7.5).multiply(image.select('B2')))
    .add(ee.Image(1))
  );

// عرض النتائج
Map.addLayer(ndvi, {min: -0.2, max: 0.8, palette: ['blue', 'white', 'green']}, 'NDVI');
Map.addLayer(ndwi, {min: -0.5, max: 0.5, palette: ['brown', 'white', 'blue']}, 'NDWI');
