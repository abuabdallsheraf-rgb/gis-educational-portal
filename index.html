🌟 مقدمة عن GIS

  "C:/GIS_Project/Agriculture_GIS.gdb",
  "Soil_Samples", "POINT"
)

# إضافة Domain للتربة

  "C:/GIS_Project/Agriculture_GIS.gdb",
  "SoilTypeDomain", "Soil Types", "TEXT", "CODED"
)

الوحدة الخامسة: المؤشرات النباتية
🌿

NDVI

الصيغة: (NIR - Red) / (NIR + Red)

المؤشر الأكثر استخداماً لتقييم صحة النبات.

كلاسيكي
🌱

EVI

الصيغة: G × (NIR - Red) / (NIR + C1×Red - C2×Blue + L)

محسن، أقل تأثراً بالغلاف الجوي.

محسن
💧

NDWI

الصيغة: (Green - NIR) / (Green + NIR)

لكشف المسطحات المائية ورطوبة التربة.

مائي

حساب NDVI في Google Earth Engine

// تحميل صورة Landsat 8
var image = ee.Image('LANDSAT/LC08/C02/T1_L2/LC08_176039_20230101');

var red = image.select('SR_B4');
var nir = image.select('SR_B5');

// حساب NDVI
var ndvi = nir.subtract(red).divide(nir.add(red));

// عرض النتيجة
Map.addLayer(ndvi, {min: -0.2, max: 0.8, palette: ['blue', 'white', 'green']}, 'NDVI');
