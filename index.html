الوحدة الثانية: التحليل المكاني (Spatial Analysis)

📊 مقدمة في التحليل المكاني

التحليل المكاني (Spatial Analysis) هو مجموعة من التقنيات التي تهدف إلى فهم العلاقات والأنماط بين الظواهر الجغرافية المختلفة. يعتبر التحليل المكاني جوهر نظم المعلومات الجغرافية، حيث يحوّل البيانات الخام إلى معلومات قيمة تدعم اتخاذ القرار.

📍 Buffer Analysis (تحليل النطاقات)

تحليل النطاقات (Buffer) هو عملية إنشاء منطقة عازلة حول معالم جغرافية (نقاط، خطوط، أو مضلعات) على مسافة محددة. يُستخدم لتحديد المناطق المتأثرة أو مناطق الحماية.

📌 أنواع النطاقات:

  • 📍 نطاق نقطي
  • 〰️ نطاق خطي
  • ▣ نطاق مضلعي
  • 📐 نطاق متعدد
⭕

مثال: مناطق حماية الآبار

📍 بئر مياه → نطاق 500 متر

منطقة حماية من التلوث

🔀 Overlay Analysis (تحليل التراكب)

تحليل التراكب (Overlay) هو عملية دمج طبقتين أو أكثر من البيانات المكانية لإنتاج طبقة جديدة تحتوي على معلومات مجمعة.

∩
Intersect

يحتفظ بالمناطق المشتركة بين الطبقات

∪
Union

يجمع جميع المناطق من جميع الطبقات

✂️
Clip

يقص طبقة باستخدام حدود طبقة أخرى

🔗
Dissolve

يدمج المعالم المتجاورة حسب صفة مشتركة

🔗 Spatial Join (الربط المكاني)

الربط المكاني (Spatial Join) هو عملية نقل البيانات الوصفية من طبقة إلى أخرى بناءً على العلاقة المكانية بينهما.

📌 أنواع الربط:

  • 🔗 One-to-One
  • 🔗 One-to-Many
  • 📍 Join by Location
  • 📊 Join by Attribute
📋

مثال: ربط الآبار بمناطق الدراسة

📍 الطبقة الأولى: نقاط الآبار

🗺️ الطبقة الثانية: مضلعات مناطق الدراسة

أكواد برمجية تطبيقية

📍 ArcGIS Pro - Python (ArcPy)

# Buffer Analysis
import arcpy
arcpy.analysis.Buffer("wells.shp", "wells_buffer_500m.shp", "500 Meters")

# Intersect (Overlay)
arcpy.analysis.Intersect(["soils.shp", "landuse.shp"], "soils_landuse.shp")

# Spatial Join
arcpy.analysis.SpatialJoin("fields.shp", "yield_points.shp", "fields_yield.shp")
الوحدة الثالثة: الجيوداتابيس (Geodatabase)

🗄️ مقدمة في الجيوداتابيس (Geodatabase)

الجيوداتابيس (Geodatabase) هي قاعدة بيانات جغرافية متطورة تُستخدم لتخزين وإدارة البيانات المكانية والوصفية بشكل مركزي ومنظم. تعتبر الجيوداتابيس العمود الفقري لأي نظام معلومات جغرافي حديث.

🗄️ مفهوم Geodatabase

الجيوداتابيس (Geodatabase) هي قاعدة بيانات علائقية مصممة خصيصاً لتخزين وإدارة البيانات المكانية مع البيانات الوصفية المرتبطة بها.

📌 مميزات Geodatabase:

  • ✅ تخزين مركزي
  • 🔗 تكامل البيانات
  • 🛡️ أمان البيانات
  • ⚡ أداء عالي
🗄️

Geodatabase = GIS + Database

📂 أنواع Geodatabase

📁
File Geodatabase
  • ✅ تخزين: ملفات على القرص الصلب
  • ✅ السعة: غير محدودة
  • 📌 الاستخدام: مشاريع صغيرة ومتوسطة
💾
Personal Geodatabase
  • ✅ تخزين: Microsoft Access
  • ⚠️ السعة: 2GB كحد أقصى
  • 📌 الاستخدام: مشاريع صغيرة جداً
🏢
Enterprise Geodatabase
  • ✅ تخزين: SQL Server, Oracle
  • ✅ السعة: غير محدودة
  • 📌 الاستخدام: مؤسسات حكومية وكبيرة

🏷️ Feature Class

Feature Class هي مجموعة من المعالم الجغرافية من نفس النوع (نقاط، خطوط، أو مضلعات) التي تشترك في نفس نظام الإحداثيات و نفس السمات.

📌 أنواع Feature Class:

  • 📍 Point
  • 〰️ Line
  • ▣ Polygon
  • 📐 Multipoint
📋

مثال: Feature Class للآبار

📍 النوع: Point

📋 السمات: Well ID, Depth, Yield

🔢 Domains (النطاقات)

Domains هي قواعد التحقق من صحة البيانات التي تُطبق على الحقول في Feature Class، تضمن أن القيم المدخلة تقع ضمن نطاق محدد.

📌 أنواع Domains:

  • 🔢 Range Domain
  • 📋 Coded Domain
  • 📅 Date Domain
  • 🔣 Text Domain
✅

مثال: Soil_Type Domain

📋 القيم: Sandy, Clay, Loam

📊 النطاق: pH 4.5 - 9.0

أكواد برمجية لإنشاء Geodatabase

📍 ArcGIS Pro - Python (ArcPy)

import arcpy

# إنشاء File Geodatabase
arcpy.management.CreateFileGDB("C:/GIS_Project", "Agriculture_GIS.gdb")

# إنشاء Feature Class
arcpy.management.CreateFeatureclass(
    "C:/GIS_Project/Agriculture_GIS.gdb",
    "Wells", "POINT"
)

# إنشاء Domain
arcpy.management.CreateDomain(
    "C:/GIS_Project/Agriculture_GIS.gdb",
    "Soil_Type_Domain",
    "أنواع التربة",
    "TEXT", "CODED"
)

الوحدة الخامسة: المؤشرات النباتية (Vegetation Indices)

🌿 مقدمة في المؤشرات النباتية

المؤشرات النباتية (Vegetation Indices) هي عمليات حسابية رياضية تُطبق على قيم الانعكاسية في النطاقات الطيفية المختلفة للصور الفضائية، بهدف تقييم الغطاء النباتي وحالته الصحية.

NDVI Normalized Difference Vegetation Index
NDVI = (NIR - Red) / (NIR + Red)

📌 التفسير:

  • 🌿 0.6 - 1.0: نباتات كثيفة وصحية
  • 🌱 0.4 - 0.6: نباتات متوسطة
  • 🍂 0.2 - 0.4: نباتات ضعيفة
  • 🏜️ 0.0 - 0.2: تربة عارية

📋 متى نستخدم NDVI؟

  • ✅ تقييم صحة النبات بشكل عام
  • ✅ مراقبة نمو المحاصيل موسمياً
  • ✅ تقدير الغطاء النباتي
EVI Enhanced Vegetation Index
EVI = G × (NIR - Red) / (NIR + C1×Red - C2×Blue + L)

📋 متى نستخدم EVI؟

  • ✅ المناطق ذات الغطاء النباتي الكثيف
  • ✅ المناطق المتأثرة بالغلاف الجوي
SAVI Soil Adjusted Vegetation Index
SAVI = ((NIR - Red) / (NIR + Red + L)) × (1 + L)

📋 متى نستخدم SAVI؟

  • ✅ المناطق ذات التربة المكشوفة
  • ✅ المناطق القاحلة وشبه القاحلة
NDWI Normalized Difference Water Index
NDWI = (Green - NIR) / (Green + NIR)

📋 متى نستخدم NDWI؟

  • ✅ كشف المسطحات المائية
  • ✅ مراقبة رطوبة التربة

📊 جدول مقارنة المؤشرات النباتية

المؤشر المعادلة الاستخدام المدى
NDVI(NIR-Red)/(NIR+Red)صحة النبات-1 → +1
EVIG×(NIR-Red)/(NIR+C1×Red-C2×Blue+L)نباتات كثيفة-1 → +1
SAVI((NIR-Red)/(NIR+Red+L))×(1+L)تربة مكشوفة-1 → +1
NDWI(Green-NIR)/(Green+NIR)كشف المياه-1 → +1

التحليل الطبوغرافي والهيدرولوجي هو حجر الأساس في فهم الخصائص الفيزيائية للأرض وسلوك المياه السطحية. يعتمد هذا التحليل على نماذج الارتفاع الرقمية (DEM) المستخرجة من بيانات الاستشعار عن بعد.

⛰️ تحليل طبوغرافي 💧 تحليل هيدرولوجي 🌊 نمذجة انجراف 🛰️ استشعار عن بعد

📐 نموذج الارتفاع الرقمي (DEM)

نموذج الارتفاع الرقمي (DEM) هو تمثيل رقمي للتضاريس السطحية للأرض، حيث يتم تخزين قيم الارتفاع في شبكة من الخلايا (Raster).

📌 مصادر DEM:

  • 🛰️ SRTM (30m, 90m)
  • 🛰️ ASTER GDEM (30m)
  • 🛰️ ALOS AW3D30 (30m)
  • 🛰️ LiDAR (دقة عالية)
⛰️

تطبيقات DEM

الانحدار الاتجاه الظل الأحواض

📐 تحليل الانحدار (Slope)

الانحدار (Slope) هو معدل التغير في الارتفاع بالنسبة للمسافة الأفقية.

📌 تصنيف الانحدار:

  • 🌾 0-2%: أراضٍ مسطحة
  • 🌱 2-8%: أراضٍ متموجة
  • ⛰️ >30%: أراضٍ وعرة

🧭 تحليل الاتجاه (Aspect)

الاتجاه (Aspect) هو اتجاه الانحدار بالنسبة للشمال الجغرافي.

📌 تصنيف الاتجاهات:

  • 🧭 شمالي: رطوبة أعلى
  • 🧭 جنوبي: جفاف أعلى

🌊 تحديد الأحواض المائية والخصائص المورفومترية

الحوض المائي (Watershed) هو منطقة تصريف تتجمع فيها المياه السطحية وتتدفق إلى نقطة تصريف واحدة.

📌 خطوات تحديد الأحواض:

  1. معالجة DEM (Fill Sinks)
  2. حساب اتجاه التدفق (Flow Direction)
  3. حساب تراكم التدفق (Flow Accumulation)
  4. استخراج شبكة التصريف (Stream Network)
  5. تحديد الأحواض (Watershed)

📊 الخصائص المورفومترية:

  • 🔹 مساحة الحوض (A): km²
  • 🔹 محيط الحوض (P): km
  • 🔹 كثافة التصريف (D): km/km²
  • 🔹 نسبة الشكل (Rf): A/L²

💻 أمثلة تحليلية على Google Earth Engine

// حساب NDVI لمنطقة شمال غرب ليبيا
var region = ee.Geometry.Polygon([[11.5,31.5],[13.5,31.5],[13.5,33.0],[11.5,33.0]]);
var s2 = ee.ImageCollection('COPERNICUS/S2_SR')
  .filterBounds(region).filterDate('2023-01-01','2023-12-31');
var ndvi = s2.map(function(img) {
  return img.select('B8').subtract(img.select('B4'))
    .divide(img.select('B8').add(img.select('B4'))).rename('NDVI');
});
Map.addLayer(ndvi.mean(), {min:-0.2,max:0.8,palette:['brown','yellow','green']}, 'NDVI');
